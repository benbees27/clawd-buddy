# clawd-buddy

A pixel Claude buddy that sits in a strip above the prompt in Claude Code and acts out what Claude is doing. He reads, types, browses, sends helpers, celebrates when a turn ends, and falls asleep when idle. A label beside him says what he is doing, such as "reading register.tsx".

## Commands

- `/buddy dance`, `/buddy wave`, `/buddy celebrate`, `/buddy sleep`, `/buddy think`: do one trick.
- `/buddy` with no word: a random trick.
- `/buddy hide` and `/buddy show`: hide him or bring him back.

## Install

```
/plugin install clawd-buddy --marketplace benbees27/clawd-buddy
```

Type `y` to add the marketplace, then choose a scope. In the desktop app, click + next to the prompt box, then Plugins, Add marketplace with `benbees27/clawd-buddy`, then Add plugin.

## Notes

- In a plain terminal there is no picture, so he shows as a small block-art mark and the label.
- The drawings are SVG and run in the desktop app.
